Datenschutzhinweise

Hinweise zur Funktion dieses Website-Entwurfs.

Diese Seite beschreibt den aktuellen Entwurf. Sie ist noch keine vollständige Datenschutzerklärung für eine öffentlich betriebene Unternehmenswebsite.

Projektanfrage

Das Formular bereitet eine Zusammenfassung im Browser vor. Die Website sendet die eingegebenen Daten nicht automatisch an BABIN BAU. Sie können die Zusammenfassung selbst kopieren oder als Textdatei herunterladen. Nach dem Eintragen einer Kontaktadresse kann zusätzlich ein E-Mail-Entwurf in Ihrem eigenen E-Mail-Programm geöffnet werden.

Bilder und eingebundene Inhalte

Für die Bildanzeige werden öffentlich abrufbare Fotos aus BABIN-BAU-Inseraten über die Server von Kleinanzeigen eingebunden (img.kleinanzeigen.de). Beim Abruf können technische Verbindungsdaten wie die IP-Adresse an den externen Dienst übertragen werden. Sollte eine Aufnahme nicht geladen werden können, erscheint ein lokal gespeichertes Entwurfsbild als Ersatz. Eine vollständige Datenschutzerklärung für die live geschaltete Firmenwebsite muss vom Betreiber vor Veröffentlichung geprüft und angepasst werden.

Hosting und Verantwortlicher

Die Website-Vorschau wird über ChatGPT Sites bereitgestellt. Die vollständigen Angaben zum Verantwortlichen, zur konkreten Hosting-Konfiguration und zu den damit verbundenen Datenverarbeitungen sind noch zu ergänzen.
